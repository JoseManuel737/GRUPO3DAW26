HISTÓRICO DE TAREAS Y DESPLIEGUE - GRUPO 3

1.CREACIÓN Y CONFIGURACIÓN DEL REPOSITORIO GITHUB
1.1. Creación de un repositorio público en GitHub "GRUPO3DAW26" por parte del Integrante 1.
1.2. Configuración de permisos y adición de los integrantes del grupo como colaboradores.
1.3. Estructuración inicial de los directorios bajo el patrón de diseño Modelo-Vista-Controlador (MVC), separando la carpeta del back-end (/app) y la del front-end (/web).

2.DESARROLLO Y REPARTO DE COMPONENTES
2.1. Integrante 1: Asignación y subida de los archivos de vistas (/app/templates/), recursos de front-end (css, js, images) y la limpieza general de la estructura del repositorio.
2.2. Integrante 2: Asignación del modelo (/app/Model.php), controladores (/app/Controller.php), controlador frontal (/web/index.php) y archivo de configuración (/app/Config.php).

3.CREACIÓN Y CONFIGURACIÓN DE LA BASE DE DATOS
3.1. Creación de la base de datos MySQL en Alwaysdata bajo el nombre correspondiente (alimentos_alimentos32026).
3.2. Ejecución mediante phpMyAdmin del script SQL estructurado para la creación de la tabla "alimentos" con sus campos (energía, proteína, hidratos de carbono, fibra y grasa total).
3.3. Modificación y adaptación del archivo de configuración (/app/Config.php) para establecer la conexión correcta con el servidor de bases de datos de Alwaysdata.

4.DESPLIEGUE EN EL HOSTING
4.1. Conexión al servidor cloud de Alwaysdata mediante protocolo ssh.
4.2. Clonación y actualización de los cambios del repositorio de GitHub directamente en la ruta pública del hosting mediante comandos de git (git clone / git pull).
4.3. Verificación del funcionamiento integral de la aplicación web basada en MVC.
